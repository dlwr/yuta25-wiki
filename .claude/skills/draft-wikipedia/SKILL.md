引数: 邦題。分かれば他言語版の記事名。

出力は `tmp/wikipedia/<記事名>.wiki`（本文）と `tmp/wikipedia/<記事名>.notes.md`（要約欄・投稿手順・未掲載事項）。Wikipedia への投稿・編集 API・ブラウザ自動操作はしない。投稿はユーザーが自分の手でやる。

## 手順

1. 記事名を決める
   - ja.wikipedia で `"<邦題>"` を全文検索し、既存記事がこの作品をどう書いているかを見る。`[[...]]` の赤リンクがあればその表記を記事名にする（作成すると青くなる）
   - 既存記事が無い、または表記が割れているときは 映画.com・allcinema の表記に合わせる。記事名では `!` `?` は半角、中黒は全角。本文・Infobox の作品名も記事名と同じ字で書く（映画.com は全角「！」だが揃えない）
   - ja に記事やリダイレクトが無いことを `python3 scripts/wiki_draft.py check '<記事名>'` で確かめる
2. 資料の所在を出す: `python3 scripts/wiki_draft.py ids ko '<朝鮮語版記事名>'`（en でもよい）。各言語版の記事名と、映画.com・allcinema・KINENOTE・KMDb・KOFIC・IMDb の URL が出る
3. 他言語版の本文を保存する: `python3 scripts/wiki_draft.py source en '<記事名>' --out tmp/wikipedia/src-en.wiki`。ko も同様。出力の `lang:記事名:oldid` を控える。読むのは Infobox・導入部・あらすじ・キャスト・受賞・外部リンクだけ。スタッフ全員の列挙や無出典の解説節は読まない
4. データベースを読む。記事に書く事実と人名のカタカナはここから取る
   - 映画.com（WebFetch。スタッフ欄とキャスト欄を全員、役職・役名付きで出させる）: 邦題の表記、配給、日本公開日、上映時間、スタッフ・キャストのカタカナ、役名、解説文
   - allcinema（WebFetch）: 上映時間・配給・公開月の突き合わせ
   - KMDb（`curl` で HTML を取り、タグを落として `수상정보` `로케이션` `관람` `개봉` を grep。WebFetch は 수상정보 を取りこぼす）: 韓国公開日、等級、上映時間、製作・配給会社、撮影地、観客数、受賞。受賞は `수상정보` の行にある回次・年・部門・受賞者をそのまま写す。`기타 수상정보` の行は他の資料と食い違いやすいので、もう 1 つ資料が無ければ notes に回す
   - koreanfilm.org `kfilm<YY>.html`（WebFetch。表の列名と該当行、導入部の言及、レビュー全文を引用させる）: ソウル観客動員数と韓国映画内の順位、Darcy Paquet の評
   - 他言語版と数値が食い違ったらデータベースを採り、notes に食い違いを書く
5. リンク先を確かめる: 本文でリンクにする人物・会社・賞・地名・用語を全部 `python3 scripts/wiki_draft.py check 'A' 'B' ...` に通す
   - `exists`: 冒頭 1 文を読んで同一人物・同一概念か確かめてから `[[A]]`
   - `disambig` `redirect`（別人）`missing`: `{{仮リンク|<ja で望ましい記事名>|ko|<朝鮮語版記事名>|label=<表示名>}}`。ja で望ましい記事名は、同名の既存記事があれば ko の曖昧さ回避に倣って `カン・ソンジン (俳優)` のようにする。朝鮮語版記事名は手順 3 で保存した本文か ko の API で実在を確かめる（リダイレクト元でなく先の名前を書く）
   - 人名のカタカナは 映画.com・allcinema・既存 ja 記事・Wikidata の ja ラベルの順に探し、どこにも無い人物は名前を書かない（部門名だけ書く、Infobox から外す）。ローマ字やハングルで残さない。自分で音写しない
   - 会社名も同じ。既存 ja 記事での表記を全文検索で探す（例: シネマ・サービス）
6. 本文を書く。順に Infobox Film → 朝鮮の事物 → 導入部 → あらすじ → キャスト → 製作・公開 → 受賞 → 脚注 → 外部リンク → スタブ → DEFAULTSORT → Category
   - Infobox Film の引数は ja のもの（監督・脚本・製作総指揮・製作・出演者・音楽・撮影・編集・製作会社・配給・公開・上映時間・製作国・言語・次作）。役職は 映画.com の表記に従う。出演者の複数は `{{Unbulleted list|A|B}}`。公開は `{{Plainlist|* {{flagicon|KOR}} 1999年10月2日<ref name="kmdb"/>\n* {{flagicon|JPN}} 2001年4月28日<ref name="eiga"/>}}`。次作・前作は `{{仮リンク}}` か `[[ ]]`。画像は入れない（ja はフェアユース不可）
   - 朝鮮の事物 は `hangeul` `hanja` `alphabet-type` `alphabet`（英題）だけ。`rr` `mr` `katakana` は資料が無いので書かない
   - 導入部は `『'''記事名'''』（原題：{{lang|ko|...}}）は、[[1999年の映画|1999年]]の[[韓国映画|韓国]]の…映画。` で始め、監督・脚本、興行、日本公開、続編を各 1 文
   - 導入部・製作・公開・受賞・日本公開の各文に `<ref name="..."/>` を付け、定義は `{{Reflist|refs=...}}` にまとめる。あらすじとキャストは作品自体が出典なので ref 不要。映画.com の解説文に書いてある設定（人物紹介、動機）はそこに ref を付ける
   - 出典を付けられない文は書かない。`{{要出典}}` `{{要検証}}` で残さない。他言語版にしか無い記述（監督の発言、作品解釈、ミュージカル化、あだ名の括弧書き）は外す
   - あらすじは他言語版の要約を訳してよいが、200〜400 字に収める。訳した箇所があるなら、その言語版は手順 7 の要約欄に入れる
   - キャストは 映画.com の 4〜5 人に、ja 記事が既にあってこの作品をフィルモグラフィに載せている俳優を足す（その記事の赤リンクが青くなる）。役名のカタカナが無ければ「ガソリンスタンドの従業員」のように役柄で書く
   - 外部リンクは `{{Allcinema title|id|邦題}}` `{{Kinejun title|id|邦題}}` `{{IMDb title|id|原題}}` と KMDb の素リンク。Category は `check` で有る物だけ（1999年の映画、韓国のコメディ映画、韓国の犯罪映画、韓国で製作された映画作品、松竹配給の映画 など）。ジャンルは KMDb の 장르 に従う
7. notes を書く。`python3 scripts/wiki_draft.py summary 'en:<記事名>:<oldid>' 'ko:<記事名>:<oldid>'` の出力（要約欄の文面と翻訳告知）をそのまま載せ、続けて投稿手順・投稿前に読む箇所・出典の取り方・未掲載にした事項と理由・数値の食い違いを書く
   - 要約欄には翻訳元の oldid と LLM 利用の申告の両方が要る。ja.wikipedia の削除の方針ケースH は LLM 生成が疑われる記事を対象にしているので、申告と人手確認の明記で対抗する
   - 投稿手順: ブラウザでログイン → 記事名で新規作成 → .wiki を貼る → プレビューで赤リンク・ref・Infobox の崩れを確かめる → 要約欄を入れて投稿 → ノートに翻訳告知（insertversion に投稿後の版番号）→ Wikidata の項目に ja サイトリンクを追加
8. 報告する: 2 ファイルのパス、ユーザーが投稿前に自分で読むべき箇所（全文と各 ref）、未掲載にした事項

## やらないこと

- 投稿、編集 API、ブラウザ自動操作でのページ作成
- 曖昧さ回避ページ・別人のページへの `[[ ]]`。`check` の冒頭 1 文を読まずにリンクしない
- 出典の無い文、他言語版だけが根拠の文、出典に書いてない付け足し（「全作品中 3 位」など資料の表から読み取れない順位）
- 映画以外の記事。頼まれたら構成だけ相談して止まる
